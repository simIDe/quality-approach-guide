# Quality Approach : guide du mini-projet

Ce site accompagne le mini-projet du cours Quality Approach (Master 2 STAPS, UFR STAPS Montpellier). Il donne de quoi s'orienter seul pendant les sept semaines du projet : le brief, une liste de contrôle qualité, des fiches pratiques courtes, des modèles de documents et un exemple qui fonctionne.

Ce dépôt est un guide. Votre projet peut être organisé tout autrement.

## Par où commencer

1. Lire [le brief](brief.md) : ce qui est attendu, pour quand, et les règles.
2. Garder sous la main [la liste de contrôle](liste-de-controle.md) : les questions à se poser sur les données et sur le projet.
3. Parcourir [l'exemple](exemple.md) : un *data product* minimal, relançable en une commande.

## Les fiches pratiques

Chaque fiche répond à une question et se lit en cinq minutes.

| Fiche | Question à laquelle elle répond |
| --- | --- |
| 01 Collaborer sur GitHub | Comment travailler à trois sur le même code sans se marcher dessus ? |
| 02 Contrôler des données | Comment savoir si mes données sont bonnes ? |
| 03 Rendre un projet relançable | Quelqu'un d'autre peut-il relancer mon projet ? |
| 04 Automatiser une vérification | Comment faire tourner mes contrôles tout seuls ? |
| 05 Publier une version | Comment dire « ceci est la version livrée » ? |
| 06 Travailler avec un agent | Comment utiliser un agent de code sans perdre la main ? |
| 07 Données personnelles | Ai-je le droit d'utiliser ces données ? |
