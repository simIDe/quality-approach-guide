# Le brief

> Vous livrez un produit de données à un utilisateur précis, comme une petite équipe le ferait pour un client. Le produit doit rester très simple : une source, une transformation, une sortie suffisent. Vous êtes évalués sur la méthode plus que sur le résultat.

- **Échéance unique :** livraison le lundi 18 janvier 2027 (produit, dépôt, journal de méthode). Restitution orale le mercredi 20 janvier.
- **Règles :** l'IA est autorisée, agents compris ; chaque membre doit pouvoir expliquer n'importe quelle partie du projet ; aucun secret ni donnée personnelle n'est envoyé à un modèle ; un groupe qui utilise des données personnelles, y compris les siennes, le signale dans sa fiche produit et explique comment il les protège.
- **Taille du projet :** le groupe en est seul juge, et c'est un critère d'évaluation.

## Réduire le périmètre : trois exemples

| Trop large | Version réduite |
| --- | --- |
| Une plateforme d'analyse de toutes les données d'entraînement d'un club, toutes disciplines confondues | La charge hebdomadaire des athlètes d'un seul groupe d'entraînement, sur les huit dernières semaines |
| Une carte interactive de tous les équipements sportifs de France, avec des indicateurs d'accessibilité | Un tableau des équipements d'une seule commune, par type d'équipement, pour le service des sports de cette commune |
| Un outil qui prédit les résultats de toutes les compétitions d'une fédération | Un rapport automatique des résultats d'un club à une compétition, produit à partir d'un seul fichier de résultats |

La version réduite garde un utilisateur, une décision et une source. Elle peut s'agrandir ensuite si le temps le permet.
